Repository (Repo)

Облачная база клана

Общий сундук студии на GitHub, где лежит самый свежий билд игры, все спрайты, звуки и диалоги.

📦 github.com/rameev-studio/kernel-valley
Commit (Коммит)

Точка сохранения (Save)

Сейв перед боссом с понятной подписью. Если дальше всё сломалось — загружаем сейв в один клик.

💾 git commit -m "Добавил посадку кукурузы"
Branch (Ветка)

Параллельная вселенная

Личная песочница: Илья делает экономику, а Данила — монстров, и никто не ломает основной мир main.

🌿 git branch feature/ddos-monsters
Pull Request & Merge

Фейсконтроль перед патчем

Заявка на слияние твоей ветки с основной игрой после проверки отделом QA.

✅ Merge Pull Request #12 -> main
Не только для кода!

Зачем GitHub художникам, сценаристам и QA?
