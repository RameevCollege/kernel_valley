Как не сломать общий проект?

Прямой коммит в master заблокирован настройками репозитория (чтобы никто случайно не перезаписал чужую работу). Слияние (Merge) всех веток в единого «монстра» мы проводим вместе на следующем созвоне!

Как устроен Git под капотом

Почему коммит файла на 1000 строк весит всего пару байт и как работает машина времени .git

На занятии мы разобрали главный принцип Git: коммиты не перезагружают ваши файлы целиком заново. Если у вас есть скрипт игры на 1000 строк и вы поменяли в нём всего 2 строчки, коммит сохранит только дельту изменений (эти 2 строки и ссылку на место вставки относительно предыдущего коммита).

Скрытая папка .git

Включите показ скрытых файлов в папке проекта: внутри .git лежат все ветки (branches), история объектов, хуки и логи каждого вашего действия.

Кнопка «Отменить» (Discard)

Случайно удалили README.md или сломали код в папке? Вкладка Source Control в VS Code видит удаление и в 1 клик достаёт файл из предыдущего коммита!

Как выжимать максимум из бесплатных моделей в Kilo Code, экономить лимиты токенов и не дать агенту случайно грохнуть вашу систему.

01 · Разметка Markdown (.md) Экономит кучу токенов

Учите синтаксис Markdown — это родной язык агентов

Файлы README.md и AGENTS.md пишутся в разметке Markdown. Таблицы, заголовки и цитаты размечаются простыми символами, весят минимум токенов и нативно открываются в Word, LibreOffice или экспортируются в HTML, PDF и DOCX.

# Заголовок 1  │  ## Заголовок 2
> Важная цитата или правило для агента
| Отдел | Ветка | ← текстовая таблица без лишних тегов
02 · Английский язык ×2 меньше расход токенов

Пишите запросы агенту на английском

Внутренний стек у Kilo Code англоязычный. Когда вы пишете промпт на русском, кириллица разбивается на большее число токенов — вы сжигаете в 2 раза больше лимита! Учитывая ограничения Kilo Code на 1 час, 5 часов, сутки и неделю, английский язык удваивает ваше время работы.

RU: ~42 токена за фразу EN: ~19 токенов за ту же мысль
03 · Copy Relative Path Разбор бага с урока

Давайте бесплатным моделям точную опору

Бесплатные модели (Auto-Free) глупее платного Claude Opus: когда Юрий написал «создай ветки согласно планам из спринтов», агент создал ненужные ветки sprint-1 и sprint-2. Нажимайте ПКМ по папке → Copy Relative Path и чётко перечисляйте, что именно создать (ветки для команд team-dev, team-art и т.д.).

❌ «Создай нужные ветки из спринтов»
✅ «Create branches for separate teams (dev, art, gd, sound) using info from sprints/sprint_1.html»
04 · Безопасность и этикет Не включать Auto-approve!

Проверяйте команды терминала и хвалите нейросеть

1) Никогда не ставьте галочку Auto-approve: всегда читайте команду, которую агент хочет выполнить в вашей консоли. Не знаете команду Linux/Git — спросите у DeepSeek в браузере, чтобы агент ничего не удалил.
2) Хвалите агента («Отлично, спасибо!»): исследования подтверждают, что позитивное подкрепление реально повышает качество следующего ответа LLM.

✅ База для старта Бесплатно

Kilo Code (VS Code)

Опенсорсный плагин с режимом Auto (Free). Сам выбирает бесплатную модель под сложность запроса. Работает сразу без покупок и карт.

  • Идеален для задач нашего спринта
  • Лимиты: на 1ч, 5ч, сутки и неделю
  • Бесплатным моделям нужны чёткие промпты
💡 Ставить только оригинал с белой галочкой (~1.7M скачиваний).
🔥 Топ-выбор (Платный) Аккаунт Pro США

Google Antigravity

Лучшая замена Claude Code для серьёзной автоматизации и фриланса. Внутри две мощные модели с отдельными лимитами:

  • 1. Модель Argon: супер-умный архитектор (пишет подробный план To-Do).
  • 2. Модель Hydrogen: большая рабочая лошадка на каждый день (выполняет To-Do).
  • 3. Сайт Gemini: третий отдельный пул токенов для планирования!
🎯 Схема Юрия: План пишем в Argon (или на сайте Gemini) → код пишем в Hydrogen = ×3 больше токенов!
⛔ НЕ ПОКУПАТЬ СЕЙЧАС Волна банов

Claude Code

Технически шикарный инструмент, но 2 недели назад перед выходом компании на биржу (IPO) прошла жёсткая зачистка аккаунтов по всему миру.

  • Тотальный бан аккаунтов из РФ, СНГ и даже Казахстана
  • У Юрия заблокировали 2 аккаунта (на $200 и $20)
⚠️ Деньги на ветер: сейчас из РФ/СНГ без шансов.
⚠️ Жёсткие лимиты 20 минут работы

ChatGPT + GitHub Copilot

У ChatGPT сейчас микроскопические лимиты при огромном расходе токенов: пятичасовой лимит сгорает буквально за 20 минут сборки одной презентации.

  • ChatGPT не годится для длительного кодинга
  • GitHub Copilot хорош только как резерв (написать коммит, мелкая правка)
📌 Copilot держим про запас на случай, если основные агенты отвалились.
Памятка: как правильно покупать аккаунт для Antigravity (Plati.Market / GGSel / Playerok)
1. Только готовый аккаунт

Не берите «инвайт в семью» на свой старый аккаунт: если страна регистрации или прошлых платежей (например, США/Германия) не совпадёт со страной продавца (Вьетнам/Сингапур), инвайт не примется. Готовый аккаунт стоит на ~200 ₽ дороже, но работает сразу.

2. Страна аккаунта = ваш VPN

Если у вас стабильный VPN в США — ищите прямо в названии товара штатовский аккаунт (USA). С российских аккаунтов Antigravity не пускает вообще.

3. Ловушка «Pro / Plus»!

Хитрые продавцы пишут на картинке и в заголовке Pro, а по умолчанию в селекторе товара стоит дешёвый Plus (где нет Argon/Hydrogen, а только старый урезанный Flash 3.8). Всегда проверяйте описание и выбирайте именно Pro!

PRO-ИНЖЕНЕРИЯ ОТ ЮРИЯ OpenWRT + OpenClaw

Авто-балансировка VPN-нод микро-агентом на роутере

Чтобы не переключать VPN вручную при блокировках, Юрий поставил на роутер с прошивкой OpenWRT микро-версию агента OpenClaw (занимает всего 10 МБ на флеше и 2 МБ в ОЗУ!).

• Роутер (OpenClaw) ↔ Домашний сервер (Lubuntu + Kilo Code)
• 2 подписки VPN × 30 нод: автоматическое переключение при падении
• Трафик всех ИИ-агентов жёстко маршрутизируется только через ноды USA
