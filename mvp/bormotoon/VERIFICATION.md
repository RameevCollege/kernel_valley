# Проверка MVP · 10 ноября 2026

Проверено на локальном Chrome, без публикации на внешнем сервере.

- Чистая симуляция: генерация карты по seed, коллизии, посадка и рост, сбор,
  проверка непрерывности конвейера, стоимость и возврат при разборе, урон и его
  задержка, кража кукурузы, восстановление после поломки, найм, автоматическая
  ферма, три задачи, улучшение дома, полное условие победы.
- Проверены валидное сохранение и отклонение повреждённых данных.
- Браузер: обязательный загрузчик, готовность без искусственного таймера,
  удаление iframe, инструкции, клавиатура, клик и поиск пути к грядке,
  строительство через интерфейс, пауза, сохранение после reload.
- Проверены мастерская и сохранение рисунка, найм через сельпо, объяснение
  неверного ответа, восстановление узла, улучшение дома через диалог.
- Мобильная эмуляция 390×844: без горизонтального переполнения, кнопки доступны.
  Скриншоты загрузки, игры и мобильного вида просмотрены.
- С файлового запуска нет запросов к внешним адресам и исключений JavaScript.
- Статический HTTP проверен на 127.0.0.1: игра открывается, полоса Tron получает
  100%, новый заезд не сбрасывает её, переход уничтожает iframe.
- Отдельно прогнан автономный HTML со встроенным Tron через srcdoc.
- ZIP проверен на целостность; транскрипты и списки студентов исключены.

Скрипты: `node tests/core.cjs`, `node tests/browser.mjs`,
`python3 pack.py`, `node tests/browser.mjs out/kernel-valley.html`.
Браузерные fixtures подставляют сохранения только для отдельных проверок диалогов;
тест прохождения всей экономики и победы выполняется в чистой симуляции.

Не проверено: реальные iOS/Android, Firefox/Safari, производительность на слабом
телефоне и баланс на живой студенческой группе. Игровые числа — стартовый баланс MVP.
